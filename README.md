# lingva.lab — Digital Tools for Linguists

**Інтерактивний практикум, який допомагає працювати з мовними матеріалами за допомогою цифрових інструментів.** Тут можна навчитися впорядковувати тексти, знаходити потрібні слова та їхні форми, працювати зі звуком і перевіряти результати автоматичного аналізу.

Інтерфейс і пояснення — українською. Перед початком оберіть мову матеріалів: **німецьку, французьку або англійську**. Для кожної мови є свої приклади та окремий навчальний прогрес.

## Для кого цей практикум

- **Для студентів лінгвістики та філології:** щоб упевненіше користуватися цифровими інструментами в навчанні й дослідженнях. Почати можна без досвіду програмування: завдання супроводжуються поясненнями, прикладами та підказками.
- **Для студентів комп’ютерних наук:** щоб побачити, як програми працюють із живою мовою і чому однакове написання, різні словоформи чи неоднозначне речення потребують уважної перевірки.
- **Для викладачів:** щоб поєднати вправи з практичними роботами й обговорювати зі студентами не лише відповіді, а й спосіб їх отримання.

## Що ви навчитеся робити

| Навичка | Де вона стане у пригоді |
| --- | --- |
| Упорядковувати файли й робити резервні копії | Зберігати записи інтерв’ю, тексти та джерела так, щоб їх легко було знайти й відновити |
| Обирати формат даних і правильно працювати із символами | Готувати словникові записи, таблиці та багатомовні документи без втрати літер і діакритичних знаків |
| Шукати слова та словоформи за правилами | Знаходити приклади в добірці текстів і перевіряти, чи пошук не пропускає потрібні форми |
| Очищувати тексти й документувати зміни | Прибирати службові позначки з транскрипції та пояснювати, що саме було змінено |
| Зберігати історію роботи за допомогою Git | Порівнювати версії матеріалів і розуміти, коли та чому змінилася розмітка |
| Працювати з аудіо та часовими позначками | Готувати записи мовлення, позначати межі фрагментів і вимірювати їхню тривалість |
| Перевіряти розпізнавання мовлення та відповіді ШІ | Знаходити помилки, порівнювати результат із джерелом і пояснювати межі автоматичних інструментів |

Наприклад, у німецьких текстах можна шукати варіанти **Straße / Strasse**, у французьких — перевіряти запис **é** в слові **café**, а в англійських — порівнювати автоматичну транскрипцію з еталонним текстом. Мета — отримати результат і вміти пояснити, чому йому можна довіряти.

## Як побудоване навчання

У практикумі **12 розділів і 60 завдань для кожної мови**. Розділи відповідають навчальним тижням, але для самостійної практики можна рухатися у власному темпі.

| Розділ | Що досліджуємо |
| --- | --- |
| 1. Робоче середовище | Папки, назви файлів, можливості комп’ютера та резервні копії |
| 2. Дані та формати | Як зберігати текст, таблиці й словникові записи |
| 3. Unicode | Як комп’ютер зберігає літери та чому однакові на вигляд символи можуть відрізнятися |
| 4. Командний рядок: навігація | Як переходити між папками та працювати з файлами за допомогою текстових команд |
| 5. Командний рядок: пошук | Як знаходити фрагменти тексту й правильно рахувати результати |
| 6. Регулярні вирази: пошук | Як описувати шаблони для пошуку слів і форм |
| 7. Регулярні вирази: заміна | Як очищувати текст, зберігаючи потрібну інформацію |
| 8. Git | Як зберігати й порівнювати версії роботи |
| 9. Цифровий звук | Як формат і умови запису впливають на аудіоматеріал |
| 10. Praat і часові інтервали | Як позначати фрагменти запису та вимірювати їхню тривалість |
| 11. Розпізнавання та синтез мовлення | Як оцінювати автоматичну транскрипцію й досліджувати озвучення тексту |
| 12. Обробка мови та ШІ | Як працювати зі словами, початковими формами й частинами мови та перевіряти твердження ШІ |

Кожен розділ містить приклад реальної дослідницької задачі, коротку теорію, пояснення термінів, посилання на джерела, **чотири вправи з автоматичною перевіркою та одну практичну роботу** для викладача.

## Як працювати з вправами

1. **Оберіть мову матеріалів.** Пояснення залишаться українською.
2. **Прочитайте задачу й приклад.** Зверніть увагу, де ця навичка потрібна в мовному дослідженні.
3. **Виконайте вправи.** Перевірте відповідь, розберіть помилки та спробуйте ще раз. За потреби скористайтеся підказкою.
4. **Підготуйте практичну роботу.** Опишіть свій метод і результат. Якщо потрібен документ, аудіозапис або інший файл, створіть його у відповідній програмі та передайте викладачеві окремо.
5. **Завантажте звіт розділу.** Він допоможе показати виконану роботу та обговорити складні місця з викладачем.

Повторні спроби — частина навчання. Сайт зберігає відповіді, помилки, використані підказки та повторні подання, щоб можна було простежити свій шлях до результату.

Кожна подана текстова відповідь зберігається без виправлення написання чи пробілів. Для завдань із вибором історія та звіт показують номер, технічний індекс і текст кожного обраного варіанта. Нумерація на екрані починається з 1, а індекси в даних — з 0.

## Прогрес, відзнаки та звіти

За виконання завдань нараховуються **XP — бали прогресу**. Також є шість відзнак і три приховані додаткові виклики про мовні дані та дослідницькі рішення. Вони добровільні й не блокують звіти. Повторне виконання вже зарахованого завдання не додає XP.

Звіт розділу можна завантажити як HTML для перегляду в браузері або JSON для подальшої обробки. Щоб отримати PDF, відкрийте HTML-звіт і оберіть **Друк → Зберегти як PDF**. Звіт незавершеного розділу буде позначено як чернетку.

Звіт також показує загальний час у розділі, час видимої вкладки у фокусі, активний час і кількість відвідувань. Активний час зупиняється у фоні, поза фокусом або після двох хвилин без взаємодії; клавіатура, натискання, прокручування й дотики поновлюють відлік. Тривале читання без взаємодії залишається в загальному часі. Закритий браузер і перерви між відвідуваннями не враховуються. Час зберігається окремо для кожного розділу й мови. Для старих спроб тривалість не вигадується: облік починається з наступного відвідування. Це приблизний показник роботи у браузері, а не підтвердження самостійності.

**XP показують навчальний прогрес, а академічну оцінку визначає викладач.** Автоматична перевірка оцінює конкретні відповіді; якість дослідження й практичної роботи потребує окремого розгляду. Позначка «подано» означає, що роботу подано, а не що її вже перевірено.

## Що варто знати перед початком

- **Прогрес зберігається у вашому браузері на вашому пристрої.** Облікових записів і автоматичної синхронізації немає. Регулярно завантажуйте JSON-резервну копію, особливо перед зміною пристрою чи очищенням даних браузера. У приватному режимі прогрес може не зберегтися.
- **Деякі вправи використовують навчальні симулятори.** Команди й Git у браузері не змінюють файли на комп’ютері. Для частини практичних робіт потрібні справжні програми, наприклад Praat або текстовий редактор.
- **Приклади створені для навчання.** Короткі тексти не представляють усю мову, а синтетичний аудіосигнал слугує для вправ із часом, а не для висновків про вимову.
- **Звіти допомагають навчанню й обговоренню.** Локальні записи можна змінити; вони не є незалежним підтвердженням виконання роботи. Кабінету викладача та окремого підсумкового тесту цифрової грамотності поки немає.

## Як запустити сайт на своєму комп’ютері

Потрібні сучасний браузер, Node.js, Python 3 і **pnpm 10.28.2**. Відкрийте термінал у папці проєкту та виконайте:

```sh
pnpm dev
```

Після цього відкрийте <http://127.0.0.1:4173>. Щоб зупинити локальний сервер, натисніть `Ctrl+C` у терміналі. Встановлювати пакетні залежності для запуску не потрібно.

Сайт створений на звичайних **HTML, CSS і JavaScript без фреймворків**. Студенти комп’ютерних наук можуть вивчати код як приклад того, як поєднати навчальні матеріали, перевірку відповідей і збереження прогресу в браузері.
