# lingva.lab — Digital Tools for Linguists

Українськомовний інтерактивний практикум для першого курсу філології. Чисті HTML, CSS і JavaScript, без фреймворків, зовнішніх шрифтів, API-ключів або залежностей під час роботи сайту.

## Локальний запуск

```sh
pnpm dev
```

Відкрийте <http://127.0.0.1:4173>. Потрібні pnpm 10.28.2, Node.js, Python 3 і сучасний браузер. Сайт не має пакетних залежностей. Відкривати `index.html` через `file://` не рекомендовано: модулі JavaScript і Worker потребують HTTP.

## Що реалізовано

- 12 розділів за уточненою програмою, 60 завдань у кожній із трьох незалежних траєкторій: німецькій, французькій та англійській.
- У кожному розділі: реальна філологічна задача, очікуваний результат, теорія, терміни, першоджерела, 4 автоматичні перевірки та 1 прикладна робота.
- Симулятори Unix-навігації й Git, пошук/заміна regex у Worker з обмеженням часу, інспектор Unicode, візуалізація кліпінгу, синтетичний аудіосигнал, часові інтервали й експорт TextGrid, калькулятор WER.
- Локальні чернетки, часові позначки всіх подань, помилки, повторні подання, використання підказок і журнал виконаних команд.
- XP за перше успішне виконання/подання, 6 відзнак, 3 приховані методологічні виклики. Повторне виконання не дає додаткових XP.
- HTML-звіти для розділів, структуровані JSON-звіти, повна резервна копія трьох траєкторій та імпорт із попереднім підтвердженням заміни.
- Адаптивна верстка, клавіатурна навігація, доступні підписи полів, підтримка reduced motion.

Для отримання PDF завантажте HTML-звіт, відкрийте його в браузері та оберіть **Друк → Зберегти як PDF**. Незавершений розділ експортується як явно позначена чернетка.

## Межі поточної версії

Прогрес зберігається у `localStorage` на поточному пристрої та в поточному браузері. Мовні траєкторії незалежні. Для перенесення використовуйте JSON-резервну копію. Очищення даних сайту видаляє локальний прогрес; приватний режим може не забезпечувати довготривалого зберігання.

Прикладні роботи перевіряє викладач. Сайт перевіряє заповнення полів, зберігає самоопис методу та посилання/назву артефакту; самі DOCX, WAV, TextGrid та інші артефакти студенти передають окремо. Статус «подано» не означає правильність роботи. Розділ вважається пройденим після чотирьох успішних автоперевірок і подання практичної роботи. Усі повторні подання залишаються в історії.

Це формувальний навчальний інструмент. Відповіді, правила перевірки й журнали доступні на клієнті, звіти не мають серверного підпису. Для контрольованого оцінювання потрібні автентифікація, серверна фіксація подій і кабінет викладача. XP не є академічною оцінкою.

Пропорції 30% / 20% / 50% у портфоліо відтворюють пропозицію з outline. Окремий підсумковий тест цифрової грамотності на 20% поки не реалізовано; склад оцінюваного портфоліо та критерії проєкту затверджує викладач.

Unix і Git виконуються у браузерних симуляторах обмеженого набору команд. Вони не змінюють файлову систему комп’ютера. Зовнішні STT/TTS/LLM не викликаються. У браузері немає справжнього Praat, акустичного аналізатора або редактора DOCX: відповідні прикладні роботи виконуються у спеціалізованих інструментах.

Аудіофайл `assets/training-signal.wav` містить авторський синтетичний сигнал: три тони 180 / 260 / 340 Hz, моно PCM 16 kHz / 16 bit, 1.8 с. Він призначений для тренування часових вимірів, а не для фонетичних висновків. Практичні мовні мінітексти також створені для навчання й не є репрезентативним корпусом.

## Cloudflare Pages

```sh
pnpm build
```

Команда копіює тільки необхідні статичні файли в `dist/`. Залежності та мережеві запити для збірки не потрібні.

Для [Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/) у Cloudflare Pages завантажте вміст `dist/` через панель керування. Для інтеграції з Git виберіть framework preset **None**, build command `pnpm build`, output directory `dist`. Сайт не використовує Functions, бази даних або платні API.

Cloudflare підтримує [статичні HTML-сайти](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/). Конкретні актуальні квоти дивіться в [Pages limits](https://developers.cloudflare.com/pages/platform/limits/). Сайт у цій сесії не опубліковано і до облікового запису Cloudflare не підключено.

Файл `_headers` задає політику джерел контенту та інші заголовки для Pages. Звичайний Python HTTP-сервер їх не застосовує; браузерні QA-перевірки запускають тестовий сервер із цими заголовками.

## Перевірка

```sh
pnpm test
pnpm build
```

Тести перевіряють досяжність результату всіх 180 варіантів завдань, незалежність траєкторій, облік помилок і повторів, одноразове нарахування XP, Unicode, regex, знімки Git, семантику копіювання, WER та імпорт.

Додаткова браузерна перевірка використовує окремо встановлений Playwright і Chrome:

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/@playwright/test/index.mjs node tests/browser.mjs
```

Вона проходить завдання через інтерфейс, перевіряє завантаження/імпорт і адаптивність. Браузерні інструменти не є залежністю самого сайту. Артефакти QA за замовчуванням зберігаються в `/tmp/lingva-lab-qa`.

## Структура

| Файл | Призначення |
| --- | --- |
| `index.html` | Каркас сторінки, навігація, профіль |
| `styles.css` | Дизайн за наданими скриншотами, адаптивність |
| `course.js` | Програма, три мовні набори, завдання, терміни та джерела |
| `engine.js` | Перевірки, прогрес, XP, симулятори, WER, резервні копії |
| `regex-worker.js` | Ізольований пошук і заміна регулярними виразами |
| `app.js` | Інтерфейс, маршрути, збереження, звіти й завантаження |
| `docs/curriculum.md` | Узгодження з outline та лабораторними №1–3 |

Для зміни завдань редагуйте `course.js`. Зміна схеми збережених даних потребує міграції або нової версії ключа у `engine.js`. Не змінюйте значення стабільного ID завдання без продуманої міграції попередніх спроб.
